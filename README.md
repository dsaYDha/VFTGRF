# 제압사격 FPS — 1단계: 기반 시스템 + 핵심 제압 메커니즘

현대 고강도 보병전을 사실적으로 재현하는 1인칭 3D 슈팅 게임의 1단계입니다.
사격의 목적은 사살이 아니라 **제압**입니다. 적은 거의 보이지 않으며, 총구 화염·총성·탄 파열음·흙먼지 같은
단서로 위치를 추정해 그 구역에 꾸준히 탄을 보내 적이 고개를 들거나 움직이지 못하게 묶어둡니다.

- Three.js + Vite (JavaScript). 외부 3D 모델·텍스처·사운드 파일 없이 기본 도형, 캔버스 절차적 텍스처, Web Audio 합성음만 사용합니다.
- 테스트 임무 **"이동 저지"**: 5분 동안 적이 개활지를 건너 진출선(파괴된 장갑차 ↔ 트랙터 잔해)에 도달하지 못하게 막습니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(기본 `http://localhost:5173/`)를 브라우저(Chrome/Edge/Firefox 최신)로 엽니다.
브리핑 화면에서 **작전 개시**를 누르면 마우스가 화면에 고정되고 소리가 켜집니다. `Esc` 로 일시정지합니다.

배포용 빌드는 `npm run build` → `dist/` 폴더 (`npm run preview` 로 확인).

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |

| 우클릭 | 가늠자 조준 (누르는 동안, 시야 1.3배) |
| R | 재장전 |
| B | 단발 / 연발 전환 |
| 마우스 휠 | 가늠자 거리 100~600m |
| T | 잔탄 확인 (대략적인 상태만) |

크로스헤어는 없습니다. 우클릭으로 가늠자 홈과 가늠쇠를 맞춰 조준합니다. 가늠자·가늠쇠는 실제 치수(눈→가늠자 25cm, 가늠자→가늠쇠 38cm, 가늠쇠 기둥 폭 2mm)로 그려
가늠쇠 기둥은 약 3mrad, 200m 에서 약 0.6m 폭만 가립니다. 200m 밖의 사람은 가늠쇠 기둥과 비슷한 크기입니다.

## 구현한 내용

### 맵 — 늦가을 동부 스텝의 폐허가 된 집단농장 (600×600m)
- **하늘·안개·조명**: 절차적으로 만든 흐린 하늘 돔(층운 구름의 명암 얼룩이 아주 천천히 흐름, 지평선 근처는 밝은 연무 띠).
  안개색 = 하늘 지평선 색이고, 지형·식생(인스턴스 포함)·구조물·파티클·원경이 모두 같은 안개 식을 받습니다
  (카메라에서의 실제 거리 기준, 100m 약 13%, 300m 약 절반, 600m 거의 안개색). 반구광(하늘 회백색 / 땅 어두운 갈색) + 구름 뒤 약한 해,
  플레이어 주변 약 80m 안에만 아주 옅은 그림자, 그 밖의 차량·잔해·건물 아래는 접지 그림자 데칼. ACESFilmic 톤매핑 + 채도 낮은 차가운 색감.
  앰비언트 오클루전은 지형 정점색으로 굽습니다(구덩이 안쪽, 참호·수로 바닥, 건물·차량 둘레).
- **지형**: 맵 전체에 완만한 기복(파장 50~150m, 높이차 0.5~1.5m — 사격 회랑에서는 솟은 곳을 눌러 사선 유지), 밭 구획마다 방향·색이 다른 고랑
  (간격 0.45~0.7m, 노멀 + 아주 얕은 골판 메시), 테두리가 솟은 포탄 구덩이 수십 개(최근 것은 밝은 하층토 분출물, 오래된 것은 무딘 테두리·풀·고인 물,
  농로·장갑차 둘레·적 진지 앞에 더 몰림), 두 줄 바퀴 자국과 고인 물·길가 배수로, 개활지를 비스듬히 지나는 궤도 차량 자국, 하늘을 흐릿하게 비추는 물웅덩이(프레넬).
- **지면 재질**: 젖은 갈아엎은 흑토·그루터기 밭·마른 풀밭·진흙·밝은 하층토·자갈 섞인 흙길 6가지 절차적 텍스처(알베도 + 노멀)를 맵 배치 데이터
  (밭 구획·길·구덩이·수로·참호)로 만든 마스크로 섞습니다. 월드 좌표 큰 규모 색 변화 + 근거리 디테일 텍스처로 반복을 깨고, 밉맵 + 이방성 필터.
- **남쪽(플레이어)**: 동서로 이어진 관개수로 — 사다리꼴 단면(바닥 폭 1.8m, 윗폭 약 5.4~6m, 깊이 1.2m), 일부 구간에만 비탈에 밀착한 약 1×2m
  프리캐스트 판(금·어긋남·빠진 판·깨진 모서리 철근), 바닥 진흙·고인 물·갈대 군락·타이어·양동이·탄약 상자. 북쪽 둑은 수로를 팔 때 나온 흙 둔덕
  (약 0.6m)이 흉벽이 됩니다: 사격 턱에 서면 상체가 드러나고, 앉으면 둔덕 위로 고개만 내밉니다. 엎드려쏴 사격 홈 8곳, 모래주머니 사격 위치 여러 곳.
  임무는 둔덕 뒤 사격 턱에 앉아 북쪽을 보는 자세로 시작합니다. 수로를 따라 옆으로 이동하며 사격 위치를 바꿀 수 있습니다.
- **중간 지대**: 갈아엎은 흑토 밭, 말라 죽은 해바라기밭(서쪽, 고랑을 따라 줄지어 심은 검은 갈색 줄기·숙인 꽃판·마른 잎, 차량이 밀고 간 띠·빈 구간·
  들쭉날쭉한 가장자리), 군락을 이룬 마른 풀, 파괴된 장갑차(BMP-1 형, 날아가 옆으로 누운 포탑과 빈 포탑 링, 열린 해치, 벗겨져 진흙에 늘어진 궤도,
  그을음·녹), 불탄 트랙터·민간 차량(유리 없음, 녹은 타이어), 쓰러진 송전탑과 땅까지 늘어진 전선, 콘크리트 전신주(일부 쓰러짐), 포격에 부러진 나무,
  흩어진 작은 잔해(포탄 파편·빈 탄약 상자·위장망 조각·헬멧·배낭).
- **북쪽(적)**: 지그재그 참호선(깊이 1.5m) — 파낸 하층토 흉벽이 흑토보다 밝은 황갈색 띠로 보여 200m 에서도 참호선 위치는 읽히지만 안의 사람은 흉벽 뒤에 숨습니다.
  흉벽 위 흙덩이·모래주머니 줄(사격 구멍)·위장망, 통나무와 흙으로 덮은 낮은 엄체호, 참호 앞 20~40m 의 말뚝 철조망·원형 철조망(탄 통과, 이동 방해).
  지붕이 무너져 서까래만 남은 벽돌 축사 3동(벽의 포탄 구멍·그을음·벽돌 더미), 탄흔·구멍 난 곡물 저장탑, 정비 창고, 소련식 무늬 콘크리트 담장
  (쓰러진 패널 포함), 녹슨 농기계, 썩은 건초 더미, 불탄 차량. 축사 하나와 저장탑 뒤에서 가는 연기 기둥이 오릅니다.
- **연기**: 모든 연기는 부드러운 원형 스프라이트 수십 장의 파티클 기둥입니다(발원점에서 짙게 시작해 올라가며 넓어지고 옅어지다가 일정 높이에서 바람 방향으로 휨).
- **원경과 맵 경계**: 맵 밖으로 지형을 낮은 해상도로 이어 붙이고(그래픽 품질에 따라 2 / 3.5 / 4.5km 까지, 기복·수로·농로·밭 구획이 끊기지 않음), 완만한 언덕, 먼 마을 지붕·교회·
  급수탑·곡물 창고, 멀어지는 송전선·전신주 행렬, 원경 연기 기둥을 둡니다. 숲·수림대는 없습니다. 안개 때문에 거의 실루엣만 보입니다.
- 수로·참호·포탄 구덩이는 높이장(0.5m 격자)에 실제로 파여 있어 들어가 몸을 숨길 수 있습니다. 렌더 메시는 구역별 해상도로 따로 만듭니다(스커트로 틈 가림).
- 진흙: 지면 종류마다 이동 속도·스태미나 소모·발소리가 다릅니다. 이동 가능 구역을 벗어나면 경고 후 되돌립니다.

### 재질과 관통
충돌은 보이는 메시와 분리된 단순 상자·원기둥(재질 태그)으로 합니다.
- 관통 불가: 흙(지형)·흉벽·하층토, 진흙, 콘크리트(수로 판·담장·전신주), 벽돌, 모래주머니, 장갑차 차체, 강철(송전탑·농기계·헬멧), 통나무(엄체호)
- 관통 가능(속도 감소): 나무 판자·문·탄약 상자, 양철판·슬레이트, 민간 차량 차체, 얇은 칸막이벽, 타이어(고무), 배낭(천), 건초 더미
- 은폐만: 해바라기, 마른 풀·갈대, 위장망, 철조망 (탄은 통과, 적의 시야만 가림. 철조망은 이동도 막음)
- 낮은 각도로 맞으면 재질별 확률로 도탄합니다. 탄착 효과는 `materials.*.impact` (흙·진흙·하층토 먼지, 콘크리트·벽돌 먼지와 파편, 금속 불꽃, 나무 조각, 고무 부스러기, 짚, 물보라).

### 플레이어
- 걷기 3 / 달리기 5.5 / 앉아 걷기 1.8 / 포복 0.7 m/s, 자세 전환 0.4~0.8초, 눈높이 1.65 / 1.1 / 0.35m, 기울이기.
- 조준 흔들림: 자세·이동·숨참(달린 직후 크게)·부상·피제압에 따라 커지고, 엎드리거나 엄폐물 모서리에 총을 걸치면(화면 아래 "거치") 크게 줍니다.
- 피해 모델(적과 동일, 자동 회복 없음): 머리·목·방탄판 밖 몸통 1발 전투 불능 / 방탄판은 관통되지 않지만 몇 초 쓰러짐 / 팔다리 1발 부상(달리기 불가·느려짐·흔들림 증가) / 부상 상태에서 또 맞으면 전투 불능.

### 무기와 탄도 (5.45mm AK 계열)
- 30발 탄창 8개(장전 1 + 예비 7), 분당 650발, 총구 속도 880m/s, 연발 시 총구가 위로 튀는 반동.
- 탄창마다 잔탄을 따로 기억하고, 재장전하면 쓰던 탄창은 남은 탄과 함께 파우치로 돌아갑니다. 약실에 탄이 있으면 빠른 재장전, 완전히 비우면 노리쇠 후퇴 동작이 추가됩니다. 탄창 마지막 3발은 예광탄.
- 모든 탄은 발사체: 중력 + 이차 공기저항, 수명 3초, 매 프레임 이전→현재 위치 선분으로 지형·충돌체·병사(부위별)와 충돌 검사. 가늠자 거리는 같은 탄도식으로 계산한 앙각표를 씁니다.
- 탄착 효과(흙먼지 기둥, 콘크리트·벽돌 먼지와 파편, 금속 불꽃, 나무 조각, 물보라)는 거리에 따라 크기를 키워 200m 밖에서도 보입니다.
- 1인칭 총기: 도형 조합 AK-74(머즐 브레이크, 보호 귀가 달린 가늠쇠 블록, 가스관·상부 총열 덮개, 가늠자 판·리시버 덮개, 권총 손잡이,
  여러 마디로 휜 탄창), 채도 낮은 자두빛 갈색 적층목 + 무광 흑회색 금속, 장갑 낀 손과 위장복 소매(오른손 권총 손잡이, 왼손 총열 덮개,
  재장전 때 왼손이 탄창 교환). 장면을 그린 뒤 깊이를 지우고 따로 그려 벽·수로 비탈을 뚫지 않고, 장면과 같은 조명을 받습니다.
  달리는 동안에는 몸 앞에 비스듬히 낮춰 든 모습이 화면 아래쪽에 보입니다.
- 조준: 카메라가 가늠자 뒤 눈 위치에서 실제 시야각으로 그립니다. 가늠자 U홈은 눈에 가까워 크고 가장자리가 약간 흐리며(초점이 가늠쇠에 있음),
  그 가운데 가늠쇠 기둥 끝과 양옆 보호 귀가 보입니다. 총몸은 화면 아래 약 20% 안으로 내려가고, 가늠쇠 끝 = 설정한 가늠자 거리의 탄착점(영점 유지).

### 제압 시스템 (1단계의 핵심)
모든 병사(플레이어 포함)는 제압 수치(0~100)를 가집니다. 판정은 **적이 실제로 있는 위치** 기준이라 플레이어가 적을 보지 못해도 동작하고, 적이 없는 곳에 쏜 탄은 효과가 없습니다.
- 근접 통과: 탄 비행 선분과 머리·가슴 기준점 사이 최단거리 0.5m 이내 +25 / 1.5m +15 / 3m +8
- 근접 탄착: 3m 이내 +20~+6 (그 적이 숨은 바로 그 엄폐물에 맞으면 5m까지)
- 탄 하나는 적 한 명에게 한 번, 근접 통과와 근접 탄착 중 큰 값만. 예광탄 ×1.2, 병사별 내성 계수 0.7~1.3
- 같은 적에게 0.5초 안에 연달아 들어오면 2번째 70%, 3번째부터 40%
- 마지막 입력 후 2초 유지, 이후 초당 8 감소 → 한 구역에 2~3초마다 한두 발씩 꾸준히 넣어야 유지됩니다.
- 단계: 정상(0~24) / 압박(25~49: 노출 짧게, 명중률 절반, 새 이동 없음) / 제압(50~79: 고개를 못 들고 맹목 사격만) / 고착(80~100: 사격·이동 불가, 이동 중이면 즉시 엎드리거나 가까운 구덩이로 뛰어듦). 관측·사격 중 근접탄을 받으면 즉시 몸을 숙입니다.

### 적 AI
- 6명 배치: 참호 2, 축사 창문·구멍 2, 잔해·건물 모서리 1, 전방 포탄 구덩이 1. 노드마다 2~5개의 사격 위치(자세·엄폐 높이·발판).
- 순환: 엄폐 → 관측(1~3초) → 사격(단발 또는 2~3발 점사) → 엄폐 → (일정 확률로 사격 위치 변경, 참호 안 좌우 이동 등).
- 플레이어의 **추정 위치**를 기억: 관측 중 발견(거리·자세·움직임·은폐·안개), 사격 시 총구 화염(보이면 정확) 또는 총성(거리 비례 오차). 오래되면 오차가 커지고, 플레이어가 자리를 옮기면 한동안 마지막 추정 위치를 쏩니다. 발견 정보는 지연·오차를 두고 공유합니다.
- 명중률은 현실적으로 낮게: 200m에서 서서 노출되면 여러 발에 한 번, 엄폐하고 엎드리면 거의 맞지 않습니다. 적도 같은 발사체 탄도를 씁니다.
- 적 탄은 조준선(눈 → 조준점) 위에서 출발하고, 자기 흉벽·구덩이 테두리·차체에 막히면 조금 들어 올려 넘겨 쏩니다. 그래도 막히는 자리면 쏘지 않고 다음 엄폐 때 다른 사격 위치로 옮깁니다. 사격 자세로 바꾼 뒤 0.3~0.5초 견착하고 첫 발을 쏩니다.
- 참호 안 위치 변경은 참호선을 따라 움직이고, 참호로 오는 증원은 연결호로 들어와 참호선을 따라갑니다.
- **이동 시도**: 20~40초마다 한 명이 한 단계 앞으로(건물 → 참호 → 전방 구덩이 → 진출선). 출발 3~5초 전부터 다른 적들이 엄호사격을 늘립니다(적 사격이 갑자기 늘면 누군가 움직이려는 신호). 출발 조건(제압 25 미만 + 최근 3초간 근처에 탄 없음)이 안 되면 기다리다 포기(저지). 개활지는 3~5초 질주 후 엎드리기를 반복하며, 이동 중 고착되면 그 자리에 엎드려 멈춥니다(저지).
- 증원: 적이 전투 불능이 되면 30~60초 뒤 단지 뒤편에서 와서 빈자리를 채웁니다. 쓰러진 적은 그대로 남습니다.
- 모델: 기본 도형 저폴리 인체(헬멧·방탄조끼·소총·주황색 식별 테이프), 스킨드 메시 1개, 자세 보간 + 팔 IK.

### 적 위치 추정 단서 / 사운드
- 짧고 밝은 총구 화염(거리 보정), 엎드려 쏘거나 흉벽 위로 쏘면 총구 앞 흙먼지.
- Web Audio 합성음 + HRTF 3D 음향 + 음속(340m/s) 지연: 가까운/먼 총성 음색 차이, 재질별 탄착음, **초음속 파열음**(적 탄이 3m 이내를 지나면 총성보다 먼저 '딱'), 도탄음, 탄피, 재장전 동작음, 진흙·풀·물 발소리, 바람, 멀리서 울리는 포성.
- 플레이어 피제압: 파열음, 짧은 화면 흔들림, 조준 흔들림 증가, 화면 가장자리 어두워짐.

### HUD·임무·디버그
- 나침반 띠(방위각), 잔탄 확인(가득/절반 이상/절반 미만/거의 없음 + 예비 탄창 수), 사격 모드, 가늠자 거리, 자세, 부상, 남은 시간, 짧은 메시지. 적 위치 마커·미니맵·킬캠 없음.
  우상단 남은 시간·'적 진출'은 반투명 어두운 바탕 + 그림자를 깔아 흐린 하늘 위에서도 읽힙니다.
- 전투 불능이 되면 떠 있던 상황 메시지('작전 구역 경계', '재장전', 잔탄·거치 표시)를 지우고 더 띄우지 않습니다. 쓰러지는 카메라는 주변 지면보다 위에 머물러 지형을 뚫지 않습니다.
- 결과 화면: 평균 제압 유지율, 적 이동 시도/저지, 적 진출, 사용 탄약, 근접탄 비율, 피격 횟수, (참고) 사살 수.
- **F3 디버그** (누를 때마다 끔 → 전체 → 성능만 → 끔):
  - 전체: 적 위치(벽 너머로 보이는 와이어 상자)와 이름표(제압 막대·상태·거리 — 화면에서 겹치면 위로 쌓고 머리까지 가는 선을 그음),
    적이 기억하는 플레이어 추정 위치(땅 위 빨간 고리 = 추정 오차 1σ, 가운데 작은 구 — 내 눈앞 3m 안이면 숨김, 적 눈에서 이어진 연결선),
    사격 위치 후보(주황 = 사용 중), 경유점 그래프·진출선, 탄도 궤적 선(노랑 = 내 탄, 빨강 = 적 탄), 이동 시도 상태와 적별 제압·추정 출처.
  - 성능만: 디버그 표시를 그리지 않고 실제 게임 화면 그대로의 FPS·프레임 시간·가장 긴 프레임·draw call·삼각형 수·렌더 해상도·품질 프리셋·GPU 이름을 보여 줍니다
    (사용자 PC 에서 60fps 측정·보고용).
- **F4 점검 시점** (F3 디버그 중): 고정 시점 6곳을 차례로 순환합니다 — 1 수로 안 엎드려쏴 홈에서 북쪽 / 2 둔덕 뒤에 앉아 북쪽(시작 위치) /
  3 둔덕 위에 서서 북쪽 전경 / 4 중간 지대 장갑차 옆에서 북쪽(포탑·잔해가 눈앞을 막지 않는 자리를 골라 씀) / 5 남쪽 맵 경계 방향 / 6 2번 위치에서 조준.
  위치는 맵 데이터와 지형에서 매번 계산하므로 지형·수로 형상이 바뀌어도 따라갑니다.

## 성능

- 화면 후처리 패스 없음: 안개·톤매핑·색감은 각 재질 셰이더 안에서, 앰비언트 오클루전·고랑 음영은 지형 정점색으로 굽고, 물체 아래 그림자는 데칼 한 메시.
  실제 그림자는 플레이어 주변 80m 만, 그림자 맵은 플레이어가 8m 움직이면 영역을 다시 맞추고 그 밖에는 0.25초마다만 다시 그립니다.
- 탄환·파티클·파편·탄흔은 고정 용량 풀, 해바라기·풀·갈대·잔해·모래주머니는 InstancedMesh(해바라기·풀은 카메라 둘레 칸만 동적 인스턴스 버퍼에 모아
  종류마다 드로우콜 1개, 해바라기는 근거리 3D → 교차 빌보드 → 원거리 밭 표면 LOD), 정적 구조물·원경은 재질별 병합 메시, 병사는 스킨드 메시 1개(드로우콜 1).
- 지형은 5m 청크마다 필요한 만큼만 촘촘하게(수로·구덩이·참호 주변 0.5~1m, 나머지 2.5m) 만들고 100m 묶음마다 근거리/원거리 2단계 LOD + 프러스텀 컬링.
  맵 밖 원경 지형은 바깥으로 갈수록 격자가 커지는 낮은 해상도 메시입니다.
- 프레임이 떨어지면 렌더 해상도를 자동으로 낮춥니다(`render.dynamicResolution`). 그래도 느리면 일시정지 메뉴에서 그래픽 품질을 '낮음'으로 바꿉니다.
- 실제 PC 의 성능은 F3 를 두 번 눌러 '성능만' 모드에서 잽니다(FPS·프레임 시간·가장 긴 프레임·draw call·삼각형 수).

### 그래픽 품질 프리셋 (`quality.presets`)
일시정지 메뉴(브리핑 화면에도 있음)에서 낮음 / 보통 / 높음을 고르면 바로 적용되고, 고른 값은 브라우저(localStorage)에 기억됩니다. 기본은 보통(내장 그래픽 노트북 기준).
보통에서 60fps 가 안 나오면 `quality.presets.medium` 수치를 낮춥니다.

| 항목 | 키 | 낮음 | 보통 | 높음 |
| --- | --- | --- | --- | --- |
| 식생 밀도 (생성한 양에서 그리는 비율, 은폐 판정은 그대로) | `vegetationDensity` → `vegetation.density` | 0.45 | 0.7 | 1.0 |
| 식생 LOD 거리 배수 | `vegetationLod` → `vegetation.lodScale` | 0.72 | 0.85 | 1.0 |
| 지형 고해상도 메시 거리 | `terrainLod` → `terrain.mesh.lodDistance` | 90m | 120m | 150m |
| 그림자 (켜고 끌 때 재질이 한 번 다시 컴파일됨) | `shadows`, `shadowMapSize`, `shadowRadius` → `render.*` | 끔 | 1024, 2.5 | 2048, 4 |
| 원경 거리 | `distantRange` → `distant.range` | 2000m | 3500m | 4500m |
| 렌더 해상도 상한 (고배율 화면) | `pixelRatioMax` → `render.pixelRatioMax` | 1.0 | 1.25 | 1.5 |
| 안티앨리어싱 (페이지를 새로 고쳐야 적용) | `antialias` → `render.antialias` | 끔 | 켬 | 켬 |

## 개발용 도구

브라우저 콘솔에서 `__game`(게임 객체), `__test`(렌더 없이 시뮬레이션) 를 쓸 수 있습니다.
예: `__test.simulate(30)` — 30초 진행 후 적 상태 요약, `__test.aimAt(x, y, z)` — 지점 조준, `__test.view(i)` — 점검 시점 i(0~5)로 옮기고 시뮬레이션 정지,
`__test.renderInfo()` — draw call·삼각형 수.

## 이후 단계 확장 포인트

- 2단계 아군 분대: `Soldier`(세력 `friendly`, 청록 테이프)와 같은 제압·피해·무기 컴포넌트를 쓰고 `AIDirector` 와 같은 구조의 아군 지휘를 붙이면 됩니다. 제압 시스템은 이미 팀과 무관하게 모든 병사에 적용됩니다.
- 3단계 기관총: `weapons` 에 PKM 데이터(탄띠·과열 필드)를 추가하고, `Player`/`Weapon` 에 거치(양각대) 상태를 확장.
- 4~5단계: 이벤트 버스에 폭발·드론·연막 이벤트를 추가하면 제압·이펙트·사운드가 같은 방식으로 반응합니다.
