# 제압사격 FPS — 1단계: 기반 시스템 + 핵심 제압 메커니즘

현대 고강도 보병전을 사실적으로 재현하는 1인칭 3D 슈팅 게임의 1단계입니다.
사격의 목적은 사살이 아니라 **제압**입니다. 적은 거의 보이지 않으며, 총구 화염·총성·탄 파열음·흙먼지 같은
단서로 위치를 추정해 그 구역에 꾸준히 탄을 보내 적이 고개를 들거나 움직이지 못하게 묶어둡니다.

- Three.js + Vite (JavaScript). 외부 3D 모델·텍스처·사운드 파일 없이 기본 도형, 캔버스 절차적 텍스처, Web Audio 합성음만 사용합니다.
- 테스트 임무 **"이동 저지"**: 5분 동안 적이 개활지를 건너 진출선(파괴된 장갑차 ↔ 트랙터 잔해)에 도달하지 못하게 막습니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(기본 `http://localhost:5173/`)를 브라우저(Chrome/Edge/Firefox 최신)로 엽니다.
브리핑 화면에서 **작전 개시**를 누르면 마우스가 화면에 고정되고 소리가 켜집니다. `Esc` 로 일시정지합니다.

배포용 빌드는 `npm run build` → `dist/` 폴더 (`npm run preview` 로 확인).

## 구현한 내용

### 맵 — 늦가을 동부 스텝의 폐허가 된 집단농장 (600×600m)
- 낮게 깔린 회색 구름, 시정 약 600m의 안개(FogExp2), 비 온 뒤 질척한 흑토, 채도 낮은 색감. 원경 지평선과 먼 마을의 연기 기둥.
- **남쪽(플레이어)**: 동서로 이어진 관개수로(깊이 1.2m, 일부 콘크리트 측벽, 물 고인 구간, 배수관 둑)와 흙 둔덕. 수로를 따라 옆으로 이동하며 사격 위치를 바꿀 수 있습니다.
- **중간 지대**: 갈아엎은 흑토 밭, 말라 죽은 해바라기밭(서쪽), 마른 풀, 바퀴 자국 패인 농로, 포탄 구덩이 60여 개, 파괴된 장갑차와 날아간 포탑, 트랙터·민간 차량 잔해, 쓰러지거나 기운 송전탑과 늘어진 전선, 부러진 나무와 그루터기.
- **북쪽(적)**: 지붕이 무너진 벽돌 축사 3동(창문·포탄 구멍·사격 구멍·칸막이벽), 콘크리트 곡물 저장탑, 정비 창고, 잔해 더미와 무너진 소건물, 지그재그 참호선(깊이 1.5m, 흙 흉벽, 모래주머니, 사격 발판), 통나무 엄체호 3개, 위장망.
- 수로·참호·포탄 구덩이는 높이장(0.5m 격자)에 실제로 파여 있어 들어가 몸을 숨길 수 있습니다. 렌더 메시는 구역별 해상도로 따로 만듭니다(스커트로 틈 가림).
- 진흙: 지면 종류마다 이동 속도·스태미나 소모·발소리가 다릅니다. 이동 가능 구역을 벗어나면 경고 후 되돌립니다.

### 재질과 관통
충돌은 보이는 메시와 분리된 단순 상자·원기둥(재질 태그)으로 합니다.
- 관통 불가: 흙(지형)·흉벽, 콘크리트, 벽돌, 모래주머니, 장갑차 차체, 통나무
- 관통 가능(속도 감소): 나무 판자·문, 양철판·슬레이트, 민간 차량 차체, 얇은 칸막이벽
- 은폐만: 해바라기, 마른 풀, 위장망 (탄은 통과, 적의 시야만 가림)
- 낮은 각도로 맞으면 재질별 확률로 도탄합니다.

### 플레이어
- 걷기 3 / 달리기 5.5 / 앉아 걷기 1.8 / 포복 0.7 m/s, 자세 전환 0.4~0.8초, 눈높이 1.65 / 1.1 / 0.35m, 기울이기.
- 조준 흔들림: 자세·이동·숨참(달린 직후 크게)·부상·피제압에 따라 커지고, 엎드리거나 엄폐물 모서리에 총을 걸치면(화면 아래 "거치") 크게 줍니다.
- 피해 모델(적과 동일, 자동 회복 없음): 머리·목·방탄판 밖 몸통 1발 전투 불능 / 방탄판은 관통되지 않지만 몇 초 쓰러짐 / 팔다리 1발 부상(달리기 불가·느려짐·흔들림 증가) / 부상 상태에서 또 맞으면 전투 불능.

### 무기와 탄도 (5.45mm AK 계열)
- 30발 탄창 8개(장전 1 + 예비 7), 분당 650발, 총구 속도 880m/s, 연발 시 총구가 위로 튀는 반동.
- 탄창마다 잔탄을 따로 기억하고, 재장전하면 쓰던 탄창은 남은 탄과 함께 파우치로 돌아갑니다. 약실에 탄이 있으면 빠른 재장전, 완전히 비우면 노리쇠 후퇴 동작이 추가됩니다. 탄창 마지막 3발은 예광탄.
- 모든 탄은 발사체: 중력 + 이차 공기저항, 수명 3초, 매 프레임 이전→현재 위치 선분으로 지형·충돌체·병사(부위별)와 충돌 검사. 가늠자 거리는 같은 탄도식으로 계산한 앙각표를 씁니다.
- 탄착 효과(흙먼지 기둥, 콘크리트·벽돌 먼지와 파편, 금속 불꽃, 나무 조각, 물보라)는 거리에 따라 크기를 키워 200m 밖에서도 보입니다.

### 제압 시스템 (1단계의 핵심)
모든 병사(플레이어 포함)는 제압 수치(0~100)를 가집니다. 판정은 **적이 실제로 있는 위치** 기준이라 플레이어가 적을 보지 못해도 동작하고, 적이 없는 곳에 쏜 탄은 효과가 없습니다.
- 근접 통과: 탄 비행 선분과 머리·가슴 기준점 사이 최단거리 0.5m 이내 +25 / 1.5m +15 / 3m +8
- 근접 탄착: 3m 이내 +20~+6 (그 적이 숨은 바로 그 엄폐물에 맞으면 5m까지)
- 탄 하나는 적 한 명에게 한 번, 근접 통과와 근접 탄착 중 큰 값만. 예광탄 ×1.2, 병사별 내성 계수 0.7~1.3
- 같은 적에게 0.5초 안에 연달아 들어오면 2번째 70%, 3번째부터 40%
- 마지막 입력 후 2초 유지, 이후 초당 8 감소 → 한 구역에 2~3초마다 한두 발씩 꾸준히 넣어야 유지됩니다.
- 단계: 정상(0~24) / 압박(25~49: 노출 짧게, 명중률 절반, 새 이동 없음) / 제압(50~79: 고개를 못 들고 맹목 사격만) / 고착(80~100: 사격·이동 불가, 이동 중이면 즉시 엎드리거나 가까운 구덩이로 뛰어듦). 관측·사격 중 근접탄을 받으면 즉시 몸을 숙입니다.

### 적 AI
- 6명 배치: 참호 2, 축사 창문·구멍 2, 잔해·건물 모서리 1, 전방 포탄 구덩이 1. 노드마다 2~5개의 사격 위치(자세·엄폐 높이·발판).
- 순환: 엄폐 → 관측(1~3초) → 사격(단발 또는 2~3발 점사) → 엄폐 → (일정 확률로 사격 위치 변경, 참호 안 좌우 이동 등).
- 플레이어의 **추정 위치**를 기억: 관측 중 발견(거리·자세·움직임·은폐·안개), 사격 시 총구 화염(보이면 정확) 또는 총성(거리 비례 오차). 오래되면 오차가 커지고, 플레이어가 자리를 옮기면 한동안 마지막 추정 위치를 쏩니다. 발견 정보는 지연·오차를 두고 공유합니다.
- 명중률은 현실적으로 낮게: 200m에서 서서 노출되면 여러 발에 한 번, 엄폐하고 엎드리면 거의 맞지 않습니다. 적도 같은 발사체 탄도를 씁니다.
- **이동 시도**: 20~40초마다 한 명이 한 단계 앞으로(건물 → 참호 → 전방 구덩이 → 진출선). 출발 3~5초 전부터 다른 적들이 엄호사격을 늘립니다(적 사격이 갑자기 늘면 누군가 움직이려는 신호). 출발 조건(제압 25 미만 + 최근 3초간 근처에 탄 없음)이 안 되면 기다리다 포기(저지). 개활지는 3~5초 질주 후 엎드리기를 반복하며, 이동 중 고착되면 그 자리에 엎드려 멈춥니다(저지).
- 증원: 적이 전투 불능이 되면 30~60초 뒤 단지 뒤편에서 와서 빈자리를 채웁니다. 쓰러진 적은 그대로 남습니다.
- 모델: 기본 도형 저폴리 인체(헬멧·방탄조끼·소총·주황색 식별 테이프), 스킨드 메시 1개, 자세 보간 + 팔 IK.

### 적 위치 추정 단서 / 사운드
- 짧고 밝은 총구 화염(거리 보정), 엎드려 쏘거나 흉벽 위로 쏘면 총구 앞 흙먼지.
- Web Audio 합성음 + HRTF 3D 음향 + 음속(340m/s) 지연: 가까운/먼 총성 음색 차이, 재질별 탄착음, **초음속 파열음**(적 탄이 3m 이내를 지나면 총성보다 먼저 '딱'), 도탄음, 탄피, 재장전 동작음, 진흙·풀·물 발소리, 바람, 멀리서 울리는 포성.
- 플레이어 피제압: 파열음, 짧은 화면 흔들림, 조준 흔들림 증가, 화면 가장자리 어두워짐.

### HUD·임무·디버그
- 나침반 띠(방위각), 잔탄 확인(가득/절반 이상/절반 미만/거의 없음 + 예비 탄창 수), 사격 모드, 가늠자 거리, 자세, 부상, 남은 시간, 짧은 메시지. 적 위치 마커·미니맵·킬캠 없음.
- 결과 화면: 평균 제압 유지율, 적 이동 시도/저지, 적 진출, 사용 탄약, 근접탄 비율, 피격 횟수, (참고) 사살 수.
- **F3 디버그**: 적 위치(벽 너머로 보이는 와이어 상자)와 제압 막대·상태, 적이 기억하는 플레이어 추정 위치(빨간 구 + 연결선, 크기 = 오차), 사격 위치 후보(주황 = 사용 중), 경유점 그래프·진출선, 탄도 궤적 선(노랑 = 내 탄, 빨강 = 적 탄), FPS·드로우콜·이동 시도 상태.

## 폴더 구조

```
src/
  config.js            모든 수치
  main.js, style.css, devtools.js
  core/                이벤트 버스(EventBus, events), 게임 루프(Game), 입력, 난수, 수학
  world/               지형(Terrain), 충돌(CollisionWorld), 구조물, 식생, 대기, 맵 데이터, 절차적 텍스처
  units/               병사(Soldier), 저폴리 모델·자세(SoldierModel, poses), 피해 모델
  player/              플레이어 (이동·자세·거치·반동)
  weapons/             무기(Weapon), 탄도(Ballistics), 영점(zeroing), 1인칭 뷰모델
  suppression/         제압 수치(Suppressible), 제압 판정(SuppressionSystem)
  ai/                  적 AI(EnemyAI), 지휘(AIDirector), 인지(Perception), 사격 위치·경로(Navigation)
  effects/             파티클·파편·예광탄·탄착 효과
  audio/               합성음 생성(SoundBank, dsp), 재생(AudioSystem)
  ui/                  HUD, 화면(브리핑·일시정지·결과), 화면 효과, 디버그
  mission/             "이동 저지" 임무와 통계
```

시스템끼리는 `core/events.js` 의 이벤트(`shotFired`, `bulletSegment`, `bulletImpact`, `bulletNearMiss`, `unitSuppressed`, `suppressionLevelChanged`, `unitHit`, `advancePlanned` …)로 느슨하게 연결됩니다.

## 성능

- 탄환·파티클·파편·탄흔은 고정 용량 풀, 해바라기·풀·잔해·모래주머니는 InstancedMesh, 정적 구조물은 재질별 병합 메시, 병사는 스킨드 메시 1개(드로우콜 1).
- 지형은 25m 청크마다 필요한 만큼만 촘촘하게(수로 1×0.5m, 구덩이·도로 1m, 나머지 2.5m) 만들고 100m 단위로 묶어 프러스텀 컬링합니다.
- 프레임이 떨어지면 렌더 해상도를 자동으로 낮춥니다(`render.dynamicResolution`). 그래도 느리면 `render.shadows: false`, `pixelRatioMax: 1.0` 을 권장합니다.

## 개발용 도구

브라우저 콘솔에서 `__game`(게임 객체), `__test`(렌더 없이 시뮬레이션) 를 쓸 수 있습니다.
예: `__test.simulate(30)` — 30초 진행 후 적 상태 요약, `__test.aimAt(x, y, z)` — 지점 조준.
