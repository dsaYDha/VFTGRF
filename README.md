# 제압사격 FPS — 2단계: 아군 분대와 사격과 기동

현대 고강도 보병전을 사실적으로 재현하는 1인칭 3D 슈팅 게임입니다 (1단계 기반 시스템·제압 메커니즘 + 2단계 아군 분대).
사격의 목적은 사살이 아니라 **제압**입니다. 적은 거의 보이지 않으며, 총구 화염·총성·탄 파열음·흙먼지 같은
단서로 위치를 추정해 그 구역에 꾸준히 탄을 보내 적이 고개를 들거나 움직이지 못하게 묶어둡니다.

- Three.js + Vite (JavaScript). 외부 3D 모델·텍스처·사운드 파일 없이 기본 도형, 캔버스 절차적 텍스처, Web Audio 합성음만 사용합니다.
- 임무 1 **"이동 저지"** (1단계): 5분 동안 적이 개활지를 건너 진출선(파괴된 장갑차 ↔ 트랙터 잔해)에 도달하지 못하게 막습니다.
- 임무 2 **"약진 엄호"** (2단계): 아군 기동조 4명이 수로에서 적 참호 앞 구덩이 지대까지 약진합니다. 플레이어와 4번은 수로에서 엄호합니다.
  플레이어의 제압사격이 아군을 움직이게 하는 핵심입니다. 브리핑 화면에서 임무를 고릅니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(기본 `http://localhost:5173/`)를 브라우저(Chrome/Edge/Firefox 최신)로 엽니다.
브리핑 화면에서 **작전 개시**를 누르면 마우스가 화면에 고정되고 소리가 켜집니다. `Esc` 로 일시정지합니다.

배포용 빌드는 `npm run build` → `dist/` 폴더 (`npm run preview` 로 확인).

크로스헤어는 없습니다. 우클릭으로 가늠자 홈과 가늠쇠를 맞춰 조준합니다. 가늠자·가늠쇠는 실제 치수(눈→가늠자 25cm, 가늠자→가늠쇠 38cm, 가늠쇠 기둥 폭 2mm)로 그려
가늠쇠 기둥은 약 3mrad, 200m 에서 약 0.6m 폭만 가립니다. 200m 밖의 사람은 가늠쇠 기둥과 비슷한 크기입니다.

임무는 수로 안 북쪽 둔덕 뒤 사격 턱에 **앉은 자세로 북쪽을 보며** 시작합니다.

## 2단계: 아군 분대와 사격과 기동 (이번 작업)

플레이어는 엄호조입니다. 플레이어의 제압사격이 아군을 움직이게 합니다. 1단계의 제압·탄도·피해 수치는 바꾸지 않았고, 아군도 같은 시스템(병사·피해·제압·무기·인지)을 씁니다.
임무 1 "이동 저지"는 그대로 브리핑 화면에서 고를 수 있습니다.

### 분대
- 6명: **1조** 분대장·1번, **2조** 2번·3번 (기동조), **엄호조** 플레이어·4번(플레이어 오른쪽 수로). 모두 AK-74, 30발 탄창 8개.
- 적과 같은 몸 모델에 청록색 식별 테이프. 머리 위 표시는 없습니다 (Tab 을 누를 때만 반투명 표지 2초).
- 아군도 적의 정확한 위치를 모릅니다. 적마다 '추정 위치'를 기억하고(총구 화염·총성·잠깐 보임), 본 것은 콜아웃으로 분대에 알립니다(지연·오차).

### 사격과 기동 (교대 약진)
- 경로: 수로 → 구덩이 10곳을 잇는 그래프(지점 사이 15~35m) → 갈림 구덩이(L3)에서 왼쪽(장갑차 옆 깊은 구덩이)/오른쪽(가운데 얕은 구덩이) → 합류 → 돌격 대기 위치(참호 앞 약 50m 구덩이 지대).
  후반 구간은 수로에서 서쪽 참호·축사·잔해 더미로 쏘는 플레이어 사선 가까이를 지납니다. 지점마다 구덩이 안 적 쪽 경사면에 엎드릴 자리 4곳이 있습니다.
- 교대 약진: 뒤처진 조가 앞 조 자리까지, 두 조가 나란하면 지난번에 앞서지 않은 조가 다음 지점으로. 갈림길에서는 그때 사선이 덜 열린 쪽을 고릅니다.
- 분대장은 1초마다 다음 구간의 출발 조건을 봅니다.
  1. 그 구간에 사선이 닿는 적(관통 불가 엄폐물만 사선을 막는다고 봄)이 모두 **압박(25) 이상**이거나 쓰러졌다
  2. 뛸 조원의 제압 값이 25 미만
  3. 최근 2초 동안 뛸 조원 3m 안에 적 탄이 없었다
  4. 지난 약진 도착 뒤 8초 이상 (플레이어가 **G** 로 요청하면 생략)
- 판단은 실제 제압 값으로 하지만, 막힌 이유는 관측할 수 있는 말로 전합니다("흰 축사, 방위 352, 거리 250에서 아직 쏜다", "2번이 묶였다", "1번 옆에 탄이 떨어진다").
  20초 넘게 막히면 엄호 사격을 다시 요청합니다.
- 약진: 3~5초 질주 후 엎드림. 긴 구간은 중간에 한 번 엎드렸다 다시 뜀. 도착하면 엎드려 엄호(고개를 들고 관측·사격 ↔ 숙임).
- 반응: 뛰는 중 근접탄·피격 → 그 자리나 6m 안 구덩이로 엎드림, 제압이 풀리고 2초 동안 근접탄이 없으면 다시 뜀. 고착이면 사격·이동 불가.
  부상자는 더 약진하지 않고 그 자리에서 엄호만 합니다.
- 아군 사격: 추정 위치나 표적 지시 지점에 2~5초마다 단발, 적과 같은 명중률 규칙(압박이면 명중률 절반), 탄약 유한. 사선에 다른 아군(플레이어 포함)이 있으면 쏘지 않습니다.

### 아군 오사와 사격 전환
- 플레이어 탄은 아군에게도 맞고 아군을 제압합니다.
- 플레이어 사선의 약 5° 또는 3m 안, 또는 탄착점 30m 안에 아군이 있으면 분대장이 "사격 전환! 1조가 사선에 있다!" / "사격 옮겨!"
- 플레이어 탄이 아군 3m 안을 지나면 그 아군이 "아군이다! 사격 중지!"

### 콜아웃
- 화면 아래 자막 "[분대장] 2조 이동!" (최대 2줄, 약 3.5초), 무전이면 짧은 스켈치 잡음. 같은 콜아웃은 6초 안에 반복하지 않습니다.
- 적 위치는 방위(북 000°, 플레이어 기준) + 가장 가까운 지형지물 + 거리: "적 발견! 흰 축사, 방위 352, 거리 250".
- 상황 콜아웃: 이동·도착, 적 발견, 엎드려 사격 받는다, 다시 간다, 부상·쓰러짐·방탄판, 적 하나 쓰러졌다, 탄창 교환·탄 부족, 엄호 사격 요청, 표적 확인, 사격 전환, 아군 오사.
- 일시정지 메뉴: 전체·효과음·음성 볼륨, '음성 콜아웃 읽기'(브라우저 음성 합성 ko-KR, 기본 끔).

### 적 AI 변경 (2단계 임무)
- 플레이어와 아군을 모두 노립니다. 대상마다 추정 위치를 따로 기억하고, 지금 보이는 대상 > 최근 확인한 대상, 가깝고 움직이는(약진 중인) 대상을 먼저 노립니다 (`ai.targeting`).
- 처음에는 아무도 모릅니다(수로 어딘가라는 처음 추정 없음). 전진 시도 없음. 배치: 참호 2, 축사 2, 잔해 더미 1 (전방 구덩이에는 없음). 증원 최대 2명.

### 탄약 상자
- 시작 위치 옆 사격 발판에 탄약 상자(2단계 임무에서만), 300발. 옆에서 **F**: 빈 예비 탄창부터 하나씩 클립으로 채움(탄창 하나 약 8초, 그동안 총을 내려 사격 불가).
  F 를 다시 누르거나, 멀어지거나, 달리거나, 방아쇠·재장전하면 멈춥니다.

### 임무 "약진 엄호"
- 브리핑: "기동조가 개활지를 건너 적 참호 앞 구덩이 지대까지 약진한다. 너와 4번은 수로에서 엄호한다. 놈들이 고개를 못 들게 해라. 아군이 사선에 들어오면 사격을 옮겨라."
- 성공: 기동조 2명 이상이 돌격 대기 위치에 30초. 실패: 기동조 3명 전투 불능 / 플레이어 전투 불능 / 플레이어 탄에 아군 전투 불능 / 12분 초과.
- 결과 화면: 성공·실패와 이유·시간, **약진 중 위협 제압률**(약진하는 동안 그 구간에 사선이 닿는 적이 압박 이상이었던 시간 비율, 핵심 지표),
  약진 횟수·막힌 G 요청, 아군 손실, 엄호조 피격, 아군 근처를 지난 내 탄·아군 오사, 사용 탄약·근접탄 비율, (작게) 사살.

### 디버그(F3)·시뮬레이션 모드
- F3 (2단계 임무): 아군 이름표·제압 막대(청록 계열), 약진 경로 그래프와 다음 구간(초록 = 출발 가능, 노랑 = 도착 뒤 대기, 빨강 = 막힘, 파랑 = 약진 중),
  막고 있는 적에서 구간까지 빨간 선과 패널의 막힌 이유·적별 제압 값, 플레이어 사선 위험 범위(5° 선·탄착점 30m 원, 아군이 들어가면 자홍),
  아군 3m 안을 지난 플레이어 탄 위치(자홍 별표, 12초).
- 시뮬레이션 모드: 화면을 그리지 않고 임무를 N번 돌려 성공률·평균 손실·평균 시간을 냅니다.
  주소에 `?sim=20&bot=good` (bot: `good` 숙련 / `random` 아무 데나 / `none` 사격 안 함, `mission=hold` 로 임무 1), 브리핑 화면에서 **F8**(숙련 봇 10회), 콘솔 `__sim(20, 'good')`.
  숙련 봇은 실제 입력과 같은 길(조준·방아쇠·C/Z/R/F 키·G/X 명령)로 조작합니다: 드러난 적만 노리고, 다음 구간에 사선이 닿는 적을 돌아가며 2~3발씩 누르고 G,
  아군이 위험 범위에 있으면 다른 적으로 옮기고, 둔덕 뒤에서 앉아 쏘고 사이에는 엎드려 숨으며, 탄이 줄면 약진 사이에 상자에서 채웁니다.

## 화면 품질 개선 (1단계 보완)

제압·탄도·피해·AI·임무 규칙과 수치는 그대로 두고 화면 품질과 시각적 정확성만 높였습니다. 배경(늦가을 동부 스텝의 폐허가 된 집단농장, 숲·수림대 없음)은 같습니다.
외부 파일 없이 모두 절차적으로 만들고, 화면 후처리 대신 굽기(정점색)·인스턴싱·병합 메시·LOD 를 씁니다. 새 수치는 모두 `src/config.js` 에 있습니다(아래 '화면 품질' 표).

| 이전 문제 | 바뀐 점 |
| --- | --- |
| 땅이 지평선에서 하늘과 칼같이 갈리고 지면에 안개가 안 먹음 | 지형·식생(인스턴스)·구조물·파티클·원경이 모두 같은 지수형 안개(300m 약 절반, 600m 거의 안개색), 안개색 = 하늘 지평선 색. 땅에 붙은 얇은 지면 연무가 먼 지면을 서서히 밝혀 지평선이 안개 속으로 녹아듦 |
| 지형이 평면, 구덩이·고랑·바퀴 자국이 안 보임 | 완만한 기복, 실제 형상이 있는 얕은 고랑, 테두리가 솟은 포탄 구덩이(최근 것은 밝은 분출물, 오래된 것은 풀·고인 물), 두 줄 바퀴 자국·배수로·궤도 자국, 하늘을 비추는 물웅덩이 |
| 번진 얼룩 같은 지면 텍스처 | 6가지 절차적 지면 재질(알베도 + 노멀)을 맵 데이터 마스크로 섞음, 큰 규모 색 변화 + 근거리 디테일, 밉맵 + 이방성 필터 최대값 |
| 하늘은 밝고 땅은 검음, 물체가 떠 보임 | ACESFilmic + 노출·어두운 쪽 들어 올림(lift)·채도 낮은 차가운 색감, 정점색으로 구운 AO, 접지 그림자 데칼, 플레이어 주변 80m 의 옅은 그림자 |

### 맵 — 늦가을 동부 스텝의 폐허가 된 집단농장 (600×600m)
- **하늘·안개·조명**: 절차적으로 만든 흐린 하늘 돔(층운 구름의 명암 얼룩이 아주 천천히 흐름, 지평선 근처는 밝은 연무 띠).
  안개색 = 하늘 지평선 색이고, 지형·식생(인스턴스 포함)·구조물·파티클·원경이 모두 같은 안개 식을 받습니다
  (카메라에서의 실제 거리 기준, 100m 약 13%, 300m 약 절반, 600m 거의 안개색). 여기에 땅에 붙은 얇은 지면 연무와 수로 남쪽 저지대 연무를 더해
  땅을 스치는 긴 시선만 조금 더 뿌옇게 합니다(지면이 지평선 쪽으로 서서히 밝아져 안개 띠와 이어짐). 반구광(하늘 회백색 / 땅 어두운 갈색) + 구름 뒤 약한 해,
  플레이어 주변 약 80m 안에만 아주 옅은 그림자, 그 밖의 차량·잔해·건물 아래는 접지 그림자 데칼. ACESFilmic 톤매핑 + 채도 낮은 차가운 색감
  (어두운 쪽만 살짝 들어 올려 흑토가 검게 뭉개지지 않고 진한 회갈색으로 표면이 보임, 하늘은 하얗게 날아가지 않음).
  앰비언트 오클루전은 지형 정점색으로 굽습니다(구덩이 안쪽, 참호·수로 바닥, 건물·차량 둘레).
- **지형**: 맵 전체에 완만한 기복(파장 50~150m, 높이차 0.5~1.5m — 사격 회랑에서는 솟은 곳을 눌러 사선 유지), 밭 구획마다 방향·색이 다른 고랑
  (간격 0.45~0.7m, 노멀 + 아주 얕은 골판 메시), 테두리가 솟은 포탄 구덩이 수십 개(최근 것은 밝은 하층토 분출물, 오래된 것은 무딘 테두리·풀·고인 물,
  농로·장갑차 둘레·적 진지 앞에 더 몰림), 두 줄 바퀴 자국과 고인 물·길가 배수로, 개활지를 비스듬히 지나는 궤도 차량 자국, 하늘을 흐릿하게 비추는 물웅덩이(프레넬).

- 조준: 카메라가 가늠자 뒤 눈 위치에서 실제 시야각으로 그립니다. 가늠자 U홈은 눈에 가까워 크고 가장자리가 약간 흐리며(초점이 가늠쇠에 있음),
  그 가운데 가늠쇠 기둥 끝과 양옆 보호 귀가 보입니다. 총몸은 화면 아래 약 20% 안으로 내려가고, 가늠쇠 끝 = 설정한 가늠자 거리의 탄착점(영점 유지).

### 제압 시스템 (1단계의 핵심)
모든 병사(플레이어 포함)는 제압 수치(0~100)를 가집니다. 판정은 **적이 실제로 있는 위치** 기준이라 플레이어가 적을 보지 못해도 동작하고, 적이 없는 곳에 쏜 탄은 효과가 없습니다.
- 근접 통과: 탄 비행 선분과 머리·가슴 기준점 사이 최단거리 0.5m 이내 +25 / 1.5m +15 / 3m +8
- 근접 탄착: 3m 이내 +20~+6 (그 적이 숨은 바로 그 엄폐물에 맞으면 5m까지)
- 탄 하나는 적 한 명에게 한 번, 근접 통과와 근접 탄착 중 큰 값만. 예광탄 ×1.2, 병사별 내성 계수 0.7~1.3
- 같은 적에게 0.5초 안에 연달아 들어오면 2번째 70%, 3번째부터 40%
- 마지막 입력 후 2초 유지, 이후 초당 8 감소 → 한 구역에 2~3초마다 한두 발씩 꾸준히 넣어야 유지됩니다.
- 단계: 정상(0~24) / 압박(25~49: 노출 짧게, 명중률 절반, 새 이동 없음) / 제압(50~79: 고개를 못 들고 맹목 사격만) / 고착(80~100: 사격·이동 불가, 이동 중이면 즉시 엎드리거나 가까운 구덩이로 뛰어듦). 관측·사격 중 근접탄을 받으면 즉시 몸을 숙입니다.

### 적 AI
- 6명 배치: 참호 2, 축사 창문·구멍 2, 잔해·건물 모서리 1, 전방 포탄 구덩이 1. 노드마다 2~5개의 사격 위치(자세·엄폐 높이·발판).
- 순환: 엄폐 → 관측(1~3초) → 사격(단발 또는 2~3발 점사) → 엄폐 → (일정 확률로 사격 위치 변경, 참호 안 좌우 이동 등).
- 플레이어의 **추정 위치**를 기억: 관측 중 발견(거리·자세·움직임·은폐·안개), 사격 시 총구 화염(보이면 정확) 또는 총성(거리 비례 오차). 오래되면 오차가 커지고, 플레이어가 자리를 옮기면 한동안 마지막 추정 위치를 쏩니다. 발견 정보는 지연·오차를 두고 공유합니다.
- 명중률은 현실적으로 낮게: 200m에서 서서 노출되면 여러 발에 한 번, 엄폐하고 엎드리면 거의 맞지 않습니다. 적도 같은 발사체 탄도를 씁니다.
- 적 탄은 조준선(눈 → 조준점) 위에서 출발하고, 자기 흉벽·구덩이 테두리·차체에 막히면 조금 들어 올려 넘겨 쏩니다. 그래도 막히는 자리면 쏘지 않고 다음 엄폐 때 다른 사격 위치로 옮깁니다. 사격 자세로 바꾼 뒤 0.3~0.5초 견착하고 첫 발을 쏩니다.
- 참호 안 위치 변경은 참호선을 따라 움직이고, 참호로 오는 증원은 연결호로 들어와 참호선을 따라갑니다.
- **이동 시도**: 20~40초마다 한 명이 한 단계 앞으로(건물 → 참호 → 전방 구덩이 → 진출선). 출발 3~5초 전부터 다른 적들이 엄호사격을 늘립니다(적 사격이 갑자기 늘면 누군가 움직이려는 신호). 출발 조건(제압 25 미만 + 최근 3초간 근처에 탄 없음)이 안 되면 기다리다 포기(저지). 개활지는 3~5초 질주 후 엎드리기를 반복하며, 이동 중 고착되면 그 자리에 엎드려 멈춥니다(저지).
- 증원: 적이 전투 불능이 되면 30~60초 뒤 단지 뒤편에서 와서 빈자리를 채웁니다. 쓰러진 적은 그대로 남습니다.
- 모델: 기본 도형 저폴리 인체(헬멧·방탄조끼·소총·주황색 식별 테이프), 스킨드 메시 1개, 자세 보간 + 팔 IK.

## 성능

- 화면 후처리 패스 없음: 안개·톤매핑·색감은 각 재질 셰이더 안에서, 앰비언트 오클루전·고랑 음영은 지형 정점색으로 굽고, 물체 아래 그림자는 데칼 한 메시.
  실제 그림자는 플레이어 주변 80m 만, 그림자 맵은 플레이어가 8m 움직이면 영역을 다시 맞추고 그 밖에는 0.25초마다만 다시 그립니다.
- 탄환·파티클·파편·탄흔은 고정 용량 풀, 해바라기·풀·갈대·잔해·모래주머니는 InstancedMesh(해바라기·풀은 카메라 둘레 칸만 동적 인스턴스 버퍼에 모아
  종류마다 드로우콜 1개, 해바라기는 근거리 3D → 교차 빌보드 → 원거리 밭 표면 LOD), 정적 구조물·원경은 재질별 병합 메시, 병사는 스킨드 메시 1개(드로우콜 1).
- 지형은 5m 청크마다 필요한 만큼만 촘촘하게(수로·구덩이·참호 주변 0.5~1m, 나머지 2.5m) 만들고 100m 묶음마다 근거리/원거리 2단계 LOD + 프러스텀 컬링.
  맵 밖 원경 지형은 바깥으로 갈수록 격자가 커지는 낮은 해상도 메시입니다.
- 프레임이 떨어지면 렌더 해상도를 자동으로 낮춥니다(`render.dynamicResolution`). 그래도 느리면 일시정지 메뉴에서 그래픽 품질을 '낮음'으로 바꿉니다.
- 실제 PC 의 성능은 F3 를 두 번 눌러 '성능만' 모드에서 잽니다(FPS·프레임 시간·가장 긴 프레임·draw call·삼각형 수·렌더 해상도·품질 프리셋·GPU 이름).
  느리면 아래 `CONFIG.quality.presets` 의 보통(`medium`) 수치(식생 밀도·LOD 거리·그림자·원경 거리)를 낮춥니다.
- 점검 시점 기준 draw call / 삼각형 수 (1280×720, 보통): 1·2·3번 수로·둔덕 약 119 / 74만, 4번 장갑차 옆 약 104 / 61만, 5번 남쪽 약 59 / 34만,
  6번 조준 약 141 / 87만. 높음은 3번 시점 약 143 / 95만, 낮음은 약 119 / 68만 (그림자 맵을 다시 그리는 프레임은 조금 더 많음).

### 그래픽 품질 프리셋 (`quality.presets`)
일시정지 메뉴(브리핑 화면에도 있음)에서 낮음 / 보통 / 높음을 고르면 바로 적용되고, 고른 값은 브라우저(localStorage)에 기억됩니다. 기본은 보통(내장 그래픽 노트북 기준).
보통에서 60fps 가 안 나오면 `quality.presets.medium` 수치를 낮춥니다.

| 항목 | 키 | 낮음 | 보통 | 높음 |
| --- | --- | --- | --- | --- |
| 식생 밀도 (생성한 양에서 그리는 비율, 은폐 판정은 그대로) | `vegetationDensity` → `vegetation.density` | 0.45 | 0.7 | 1.0 |
| 식생 LOD 거리 배수 | `vegetationLod` → `vegetation.lodScale` | 0.72 | 0.85 | 1.0 |
| 지형 고해상도 메시 거리 | `terrainLod` → `terrain.mesh.lodDistance` | 90m | 120m | 150m |
| 그림자 (켜고 끌 때 재질이 한 번 다시 컴파일됨) | `shadows`, `shadowMapSize`, `shadowRadius` → `render.*` | 끔 | 1024, 2.5 | 2048, 4 |
| 원경 거리 | `distantRange` → `distant.range` | 2000m | 3500m | 4500m |
| 렌더 해상도 상한 (고배율 화면) | `pixelRatioMax` → `render.pixelRatioMax` | 1.0 | 1.25 | 1.5 |
| 안티앨리어싱 (페이지를 새로 고쳐야 적용) | `antialias` → `render.antialias` | 끔 | 켬 | 켬 |

## 개발용 도구

브라우저 콘솔에서 `__game`(게임 객체), `__test`(렌더 없이 시뮬레이션) 를 쓸 수 있습니다.
예: `__test.simulate(30)` — 30초 진행 후 적 상태 요약, `__test.aimAt(x, y, z)` — 지점 조준, `__test.view(i)` — 점검 시점 i(0~5)로 옮기고 시뮬레이션 정지,
`__test.renderInfo()` — draw call·삼각형 수, `__sim(20, 'good')` — 시뮬레이션 모드(렌더 없이 N회, 성공률·평균 손실·평균 시간).
